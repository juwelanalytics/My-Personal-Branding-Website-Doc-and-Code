Quick Answer

Bing Ads conversion tracking runs on the UET tag[cite: 26, 27]. Install one base UET tag across all pages via GTM, set up custom event goals with matching action names, pass required regional consent signals, and add server-side tracking for maximum data capture[cite: 26, 27].

1. Why Bing Ads Tracking Breaks Without Proper Structure

Microsoft Advertising relies heavily on UET tags to optimize automated bidding[cite: 26, 27]. When tags are installed incorrectly, or when event action parameters fail to match conversion goals character for character, conversion data is lost, degrading ad performance[cite: 27].

3. Step-by-Step Implementation Guide

Phase 1 & 2: Audit Account & Create Conversion Goals

Audit your Microsoft Advertising account, list every conversion goal, and note the exact event action criteria required[cite: 26, 27].

Phase 3 & 4: Install UET Base Tag & Custom Event Tags in GTM

Deploy the Universal Event Tracking base tag across all pages using GTM[cite: 26, 27]. Create custom event tags matching your defined goal actions[cite: 26, 27].

Phase 5, 6 & 7: Consent, Server-Side Routing & Testing

Transmit default consent states (`ad_storage`)[cite: 27]. Implement server-side CAPI tracking via Stape with shared event IDs, and verify via the UET Tag Helper extension[cite: 26, 27].

4. Troubleshooting Common Configuration Mistakes

  • Goal Says "No Recent Conversions": Check that your GTM Event Action matches the Bing Ads goal condition exactly[cite: 27].
  • Conversions Are Doubled: Ensure browser and server events utilize identical event IDs to prevent duplicate recording[cite: 27].
  • European Visitor Data Drop: Verify that regional consent signals are properly initialized and updated when visitors accept[cite: 27].

5. Frequently Asked Questions

What is the Microsoft UET tag?[cite: 27] +

It is a foundational JavaScript analytics tag provided by Microsoft Advertising that collects user activity on your website and reports conversion data back to your campaigns[cite: 26, 27].

Is consent mode required for Microsoft Ads?[cite: 27] +

Yes. To maintain regulatory compliance for traffic originating from the UK, EEA, and Switzerland, proper consent signals must be integrated with your UET implementation[cite: 27].
