1. The Event Is in the Data Layer, Now What?

Having a listener push Pipedrive submissions into the Data Layer is a vital first step, but it changes nothing in reports on its own[cite: 22, 23]. The GA4 event tag serves as the delivery mechanism that registers the submission as a countable conversion[cite: 23].

2. Untagged Data Layer vs. Configured GA4 Tags

Implementation Stage Data Layer Visibility GA4 / Ad Reporting
Raw Listener Only Visible in GTM Preview[cite: 23] None (Invisible in reports)[cite: 23]
Configured GA4 Custom Event Tag Visible & Processed[cite: 23] Active (`generate_lead` key event)[cite: 23]

3. Step-by-Step Implementation Guide

Step 1 & 2: Copy Event Name & Create Trigger

Copy the exact event string (such as `pipedrive_form_submit`) from GTM Preview[cite: 23]. Custom Event triggers are strictly case-sensitive, so avoid manual typing[cite: 23]. Create a Custom Event trigger using this exact name[cite: 23].

Step 3, 4 & 5: Configure GA4 Event Tag & Parameters

Choose the **Google Analytics: GA4 Event Tag** type[cite: 23]. Store your GA4 Measurement ID in a reusable constant variable[cite: 23]. Set the event name to `generate_lead` and attach necessary parameters like `page_location`, `page_path`, `form_platform`, and `form_id`[cite: 23].

4. Troubleshooting Common Configuration Mistakes

  • Tag Never Fires: Check for trailing spaces or capitalization discrepancies in your Custom Event trigger name[cite: 23].
  • Parameters Show as Undefined: Ensure your Data Layer Variable keys match the exact key names pushed by your listener[cite: 23].
  • Parameters Missing in Reports: Remember to register your custom parameters as event-scoped custom dimensions in GA4[cite: 23].

5. Frequently Asked Questions

What is a GA4 custom event tag in Google Tag Manager?[cite: 23] +

It is a tag configuration that listens for a specific data layer event (like a Pipedrive form submit) and fires a conversion hit containing parameters directly to your GA4 property[cite: 23].

Why don't my custom parameters show in GA4 reports?[cite: 23] +

GA4 collects custom parameters with event hits, but they remain hidden in standard UI reports until you explicitly register them as event-scoped custom dimensions under admin data display settings[cite: 23].
