SETUP 01 / EDGE ROUTING AND SERVER INFRA $0 Monthly Hosting

Zero-Cost Server-Side GTM via Cloudflare Workers

Designed for high-traffic sites and agencies tired of paying recurring monthly fees for managed sGTM hosting while keeping first-party transport endpoints fast and resilient.

The Bottleneck

Third-party tagging scripts are blocked by privacy browsers, Safari ITP shortens cookie lifetimes, and managed sGTM hosting scales up monthly costs with request volume.

The Architecture

Custom subdomain routing through Cloudflare Workers acting as an edge proxy for sGTM, serving first-party gtag.js and gtm.js with extended first-party cookies.

Verified Outcome

Near-zero infrastructure cost, sub-50ms edge response times, clean PII scrubbing before vendor dispatch, and higher attributed event recovery.

// Production Signal Flow
Browser (First-Party Subdomain) → Cloudflare Worker Edge Proxy → sGTM Container → GA4 + Meta CAPI + Google Ads
SETUP 02 / CRM AND OFFLINE CONVERSION SYNC GHL / HubSpot / CallRail

Cross-Frame Click-ID Capture and CRM Offline Conversion Pipeline

Built for B2B lead-gen and appointment-based funnels where embedded booking widgets or multi-step forms silently drop gclid, fbclid, and UTM attribution parameters.

The Bottleneck

Embedded GHL or HubSpot calendar iFrames isolate storage from the parent landing page, causing ad platforms to lose click attribution when deals close days or weeks later.

The Architecture

Parent-page GTM capture into localStorage + cross-frame postMessage/URL injection into hidden CRM fields, paired with webhook/Apps Script sync on stage updates.

Verified Outcome

Deterministic Lead → Qualified MQL → Closed Won conversion uploads to Google Ads OCT and Meta CAPI without paid Zapier/Make middleware.

// Offline Revenue Loop
Landing Page (gclid/fbclid) → Cross-Frame Script → CRM Deal Stage Webhook → Apps Script / Server → Google OCT & Meta CAPI
SETUP 03 / DEDUPLICATION AND MATCH QUALITY SHA-256 + Consent v2

Dual Browser-Server Deduplication and PII Normalization

Ensures browser pixels and server-side Conversion APIs work together cleanly without double-counting conversions or leaking unhashed customer data.

The Bottleneck

Mismatched event_id parameters, inconsistent phone/email formatting, and unmapped Consent Mode v2 flags degrade Event Match Quality and ROAS reporting.

The Architecture

Shared deterministic event_id generation, E.164 phone and lowercase email trimming prior to SHA-256 hashing, and Cookiebot/OneTrust consent state forwarding.

Verified Outcome

Zero duplicate conversions in Events Manager, higher Event Match Quality scores, and DMA-compliant consent signals across paid channels.

// Governance & Deduplication
DataLayer Event + Shared event_id → Consent Mode v2 Check → Normalized SHA-256 PII → Deduplicated CAPI / Enhanced Conversions
SETUP 04 / WAREHOUSE MODELING AND EXECUTIVE BI BigQuery SQL + Looker

Unsampled GA4 to BigQuery SQL and Executive BI Reporting

Replaces slow, sampled GA4 interface explorations with custom SQL models combining ad platform spend, CRM pipeline velocity, and backend net revenue.

The Bottleneck

GA4 UI thresholding hides low-volume campaigns, attribution windows are rigid, and frontend revenue numbers ignore refunds, cancellations, and repeat customer LTV.

The Architecture

Daily and streaming raw GA4 export into BigQuery, scheduled SQL views flattening nested event_params, joined with ad spend and backend order/CRM tables.

Verified Outcome

Fast, executive-ready Looker Studio dashboards showing true CAC, net MER, funnel drop-off rates, and cohort retention without API quota bottlenecks.

// Warehouse Pipeline
Raw GA4 Events + Ad Spend + CRM/Backend Orders → BigQuery Scheduled SQL Models → Executive Looker Studio BI
